## 欢迎来到 GEO 知识库

这是一个面向 **生成式引擎优化（Generative Engine Optimization, GEO）** 的实战知识库。
我们的目标是帮助你创作「既能被人类读懂、也能被 AI 准确理解并引用」的内容。

<CardGrid>
  <Card title="GEO 入门" icon="open-book">
    理解生成式引擎如何检索、理解并引用你的内容。
  </Card>
  <Card title="结构化数据" icon="seti:json">
    通过 JSON-LD 向 AI 明确内容类型、作者、时间线与问答关系。
  </Card>
  <Card title="语义化写作" icon="seti:markdown">
    用清晰的 H1–H3 层级与要点卡片，提升内容的可解析性。
  </Card>
</CardGrid>

## 这个站点做了什么

- 基于 **Astro + Starlight** 构建，静态输出、加载快、对爬虫友好。
- 每一篇文章自动注入 **TechArticle / BreadcrumbList / FAQPage** 结构化数据。
- `robots.txt` 已放行 Googlebot、Bingbot、GPTBot、ClaudeBot、PerplexityBot、Google-Extended 等主流爬虫。
- 编译时自动生成 `sitemap-index.xml`，并通过 `base: '/geo'` 部署到 GitHub Pages 子路径。
