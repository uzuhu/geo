## 这个站点做了什么

- 基于 **Astro + Starlight** 构建，静态输出、加载快、对爬虫友好。
- 每一篇文章自动注入 **TechArticle / BreadcrumbList / FAQPage** 结构化数据。
- `robots.txt` 已放行 Googlebot、Bingbot、GPTBot、ClaudeBot、PerplexityBot、Google-Extended 等主流爬虫。
- 编译时自动生成 `sitemap-index.xml`，并通过 `base: '/geo'` 部署到 GitHub Pages 子路径。
