把研究结论翻译成单页检查清单。逐项对照，全过即 GEO-ready：

| 检查项 | 标准 |
| --- | --- |
| 开头 | 100 字内直接给核心答案（BLUF，Bottom Line Up Front） |
| 标题 | H2/H3 用用户会真实提问的问句 |
| 事实密度 | 每 150–200 词至少一个可验证的数据或引用 |
| 结构化 | 至少一个对比表或要点列表 |
| FAQ | 底部 5–10 个真实问题 + `FAQPage` Schema |
| 作者/时间 | `Article` Schema 含作者、发布与修改日期 |
| 来源 | 关键数据标注出处（链向权威源） |
| 实体 | 内容覆盖 15+ 相关实体（产品、概念、机构等） |
| 新鲜度 | 明显的「最近更新」时间戳 |

## 两条被数据印证的提醒

1. **列表体是被抽取概率最高的形态**：列表体（listicle）占全部 AI 引用的约 **32%**，是博客/观点类内容（9.9%）的 **3 倍**。把长文改写成「要点列表 + 表格」，被抽取概率显著提升。
2. **AI 倾向抓取开篇的明确陈述**：每节开头先用一句话给出结论，再展开依据——这就是 BLUF 之所以有效的机制。

## 不要全站一起改

挑**最有价值的 10 个页面**（流量最大、转化最好、最能代表专业能力）先改。优先级策略见 [小团队资源有限，优先级怎么排？](../small-team-priority/)。
